# คู่มือใช้งาน Prompt Hub

## ผู้เยี่ยมชม (ไม่ต้องเข้าสู่ระบบ)

1. **ค้นหา** — พิมพ์คำในช่องค้นหาหน้าแรก ระบบค้นจากชื่อ คำอธิบาย เนื้อหา และแท็ก
2. **กรองและเรียง** — หน้า “สำรวจ Prompt” เลือกหมวดหมู่ เครื่องมือ AI จำนวนต่อหน้า และเรียงตาม “ล่าสุด” หรือ “คัดลอกมากที่สุด” ใช้ร่วมกันได้ เปลี่ยนหน้าแล้วค่าค้นหาและตัวกรองยังอยู่ กดแท็กบนการ์ดเพื่อกรองตามแท็ก
3. **ใช้ Prompt** — เปิด “ดูรายละเอียด”
   - ถ้า Prompt มีตัวแปร เช่น `[ชื่อสินค้า]` จะมีช่องให้กรอก ข้อความในกล่อง “ข้อความพร้อมคัดลอก” จะเปลี่ยนตามทันที (ต้นฉบับไม่เปลี่ยน)
   - ผู้เยี่ยมชมเห็นเนื้อหาเพียงบางส่วน ต้อง **เข้าสู่ระบบหรือสมัครสมาชิก** ก่อนจึงจะเห็นเต็มและคัดลอกได้
   - สมาชิกกด **คัดลอก Prompt** แล้วนำไปวางในเครื่องมือ AI หากเบราว์เซอร์ไม่อนุญาตให้คัดลอกอัตโนมัติ ระบบจะเลือกข้อความไว้ให้ กด Ctrl+C
   - Prompt สร้างภาพอาจมี **ภาพตัวอย่างผลลัพธ์** แสดงด้านบน กดที่ภาพเพื่อเปิดขนาดเต็ม
4. **สมัครสมาชิก** — ใช้ชื่อผู้ใช้ภาษาอังกฤษ/ตัวเลข/_ อีเมล และรหัสผ่านอย่างน้อย 8 ตัวอักษร แล้วติ๊กยอมรับนโยบายความเป็นส่วนตัว (อ่านได้จากลิงก์ส่วนท้ายทุกหน้า) หรือกด **สมัครด้วยบัญชี Google** (เมื่อผู้ดูแลเปิดใช้) ครั้งแรกตั้งชื่อผู้ใช้และยอมรับนโยบาย ครั้งต่อไปกด **เข้าสู่ระบบด้วย Google** บัญชี Google ไม่มีรหัสผ่าน ถ้าต้องการรหัสผ่านให้ใช้ “ลืมรหัสผ่าน”
5. **ลืมรหัสผ่าน** — หน้าเข้าสู่ระบบ กด “ลืมรหัสผ่าน?” กรอกอีเมลที่ใช้สมัคร แล้วเปิดลิงก์ในอีเมล (ดูโฟลเดอร์สแปมด้วย) ตั้งรหัสผ่านใหม่ภายใน 60 นาที ลิงก์ใช้ได้ครั้งเดียว หากขอหลายครั้งให้ใช้ลิงก์จากอีเมลล่าสุด ถ้าหน้าแจ้งว่า “ระบบยังไม่ได้ตั้งค่าการส่งอีเมล” ให้ติดต่อผู้ดูแล

## สมาชิก

| เมนู | ใช้ทำอะไร |
|---|---|
| แดชบอร์ด | ดูจำนวน Prompt ของคุณแยกตามสถานะ กดตัวเลขเพื่อดูรายการ และดู **แต้มสะสม** เหรียญปัจจุบัน และแต้มที่ขาดถึงเหรียญถัดไป |
| Prompt ของฉัน | ค้นหา/กรองตามสถานะและการมองเห็น แก้ไข หรือลบ |
| เพิ่ม Prompt | กรอกชื่อ คำอธิบาย เนื้อหา **คำแปลภาษาไทย** (ไม่บังคับ — แสดงใต้ต้นฉบับ ช่วยให้ผู้อื่นเข้าใจ Prompt ภาษาอังกฤษ และค้นหาด้วยคำไทยได้) หมวดหมู่ แท็ก (คั่นด้วยจุลภาค) และเครื่องมือ AI ถ้าเลือกหมวดที่รับภาพ (เช่น “การสร้างภาพ”) จะมีช่อง **ภาพตัวอย่างผลลัพธ์** แนบได้ 4 ภาพ (JPEG/PNG/WebP ไม่เกิน 5 MB) ติ๊ก “ลบภาพนี้” ใต้ภาพเดิมเพื่อเอาออก |
| รายการโปรด | Prompt สาธารณะที่บันทึกไว้ กด “ยกเลิกรายการโปรด” เพื่อเอาออก |
| โปรไฟล์ | แก้ไข **ชื่อที่แสดง ชื่อผู้ใช้ และอีเมล** (เปลี่ยนชื่อผู้ใช้/อีเมลต้องกรอกรหัสผ่านปัจจุบัน) · เปลี่ยน/ลบ **ภาพโปรไฟล์** (JPEG/PNG/WebP ไม่เกิน 2 MB ระบบตัดกลางเป็นสี่เหลี่ยมจัตุรัสให้) แก้ชื่อที่แสดง และเปลี่ยนรหัสผ่าน (ต้องกรอกรหัสผ่านปัจจุบัน) |

**ภาพที่อัปโหลด** ระบบย่อให้อัตโนมัติก่อนส่ง (ภาพตัวอย่างด้านยาวไม่เกิน 1600 px, ภาพโปรไฟล์ 256×256 px) จึงเลือกภาพความละเอียดสูงจากมือถือได้เลย ระหว่างย่อภาพปุ่มบันทึกจะกดไม่ได้ชั่วคราว

**แต้มสะสมและเหรียญรางวัล**

- ได้ 1 แต้มต่อ Prompt **สาธารณะที่ผู้ดูแลอนุมัติแล้ว** (ฉบับร่าง Prompt ส่วนตัว และรายการรอตรวจสอบยังไม่นับ)
- 5–10 แต้ม **เหรียญทองแดง** · 11–20 แต้ม **เหรียญเงิน** · 21 แต้มขึ้นไป **เหรียญทอง**
- ถ้าแก้ไข Prompt ที่เผยแพร่แล้ว แต้มของรายการนั้นจะหายชั่วคราวจนผู้ดูแลอนุมัติอีกครั้ง ลบ Prompt แล้วแต้มลดตาม
- เหรียญแสดงข้างชื่อคุณในหน้ารายละเอียด Prompt และในหน้า **ทำเนียบ** (เมนูด้านบน) ซึ่งเรียงตามแต้ม แล้วตามยอดคัดลอกรวม
- บัญชีผู้ดูแลระบบไม่ร่วมสะสมแต้ม

**การเผยแพร่**

- เลือก **ส่วนตัว** — เก็บไว้ใช้เอง ไม่มีใครเห็นนอกจากคุณและผู้ดูแล
- เลือก **สาธารณะ** แล้วกด **ส่งตรวจเพื่อเผยแพร่** — สถานะเป็น “รอตรวจสอบ” จนผู้ดูแลอนุมัติ
- ถ้าได้ “ไม่อนุมัติ” เหตุผลจะแสดงที่หน้ารายละเอียด หน้าแก้ไข และรายการ Prompt ของฉัน แก้ไขแล้วส่งตรวจใหม่ได้
- ถ้าแก้ไข Prompt ที่เผยแพร่แล้ว ระบบจะพักการเผยแพร่และรอตรวจสอบใหม่ (รายการโปรดของผู้อื่นจะซ่อนชั่วคราว)
- การลบมีกล่องยืนยันก่อนเสมอ และลบแล้วกู้คืนไม่ได้

## ผู้ดูแลระบบ

เข้าเมนู **หลังบ้าน** บนแถบด้านบน (แสดงเฉพาะบัญชีผู้ดูแล)

| หน้า | ใช้ทำอะไร |
|---|---|
| ภาพรวม | จำนวนสมาชิก Prompt หมวดหมู่ รายการรอตรวจสอบ และกิจกรรมล่าสุด |
| Prompt | ดูทุก Prompt กรองตามสถานะ/หมวด/การมองเห็น กด **อนุมัติ** ได้ทันที หรือกด **ตรวจ** เพื่อเปิดรายละเอียด |
| หน้ารายละเอียด Prompt | กล่อง “ตรวจสอบการเผยแพร่” — อนุมัติ หรือไม่อนุมัติพร้อมเหตุผล (บังคับกรอก) ใช้ถอนการเผยแพร่ Prompt ที่เผยแพร่อยู่ได้ด้วย |
| สมาชิก | ดูแต้มและเหรียญของสมาชิก กด **ลบภาพ** เพื่อลบภาพโปรไฟล์ที่ไม่เหมาะสม ค้นหา กรองบทบาท/สถานะ ระงับ/เปิดใช้งาน ตั้งเป็นผู้ดูแล/ลดเป็นสมาชิก และลบ (ลบ Prompt ของสมาชิกนั้นด้วย) |
| หมวดหมู่ | เพิ่ม แก้ไข เปิด “รับภาพตัวอย่าง” ไอคอน (ชื่อจาก Bootstrap Icons) ลำดับแสดง เปิด/ปิด หมวดที่มี Prompt ต้องเลือก “ย้ายไป…” ก่อนลบ หมวดที่ปิดจะไม่แสดงในฟอร์มเพิ่ม Prompt ใหม่ แต่ Prompt เดิมยังแสดง |
| แท็ก | ค้นหา แก้ชื่อ ลบแท็กที่ไม่เหมาะสม (สมาชิกสร้างแท็กใหม่ได้ขณะบันทึก Prompt) |
| เครื่องมือ AI | เพิ่ม แก้ไข ปิดใช้งาน (ซ่อนจากฟอร์มแต่ไม่ลบข้อมูลเดิม) หรือลบ |
| ตั้งค่าเว็บไซต์ | **เปิด/ปิดการเข้าสู่ระบบด้วย Google** พร้อมช่อง Client ID / secret และปุ่มทดสอบกับ Google · **URL เว็บไซต์** (ที่อยู่จริง ใช้ในลิงก์อีเมล Google และลิงก์แชร์ — ระบบแสดง Google redirect URI ให้คัดลอก) ชื่อเว็บไซต์ สโลแกน ป้ายบนหน้าแรก คำอธิบาย ชื่อผู้พัฒนาระบบ เจ้าของลิขสิทธิ์และปีที่เริ่มเผยแพร่ (ข้อความ © ส่วนท้ายเว็บ) และผู้ควบคุมข้อมูล/ช่องทางติดต่อที่แสดงในหน้านโยบายความเป็นส่วนตัว |
| Google Drive | ตั้งโฟลเดอร์และเชื่อมต่อ Google Drive สำหรับเก็บภาพตัวอย่างผลลัพธ์ ดูจำนวนภาพที่อยู่บน Drive/รออัปโหลด อัปโหลดภาพที่ค้าง และยกเลิกการเชื่อมต่อ (ภาพทุกภาพมีสำเนาในเครื่อง) |
| บันทึกกิจกรรม | ทุกการอนุมัติ ไม่อนุมัติ จัดการสมาชิก หมวดหมู่ แท็ก เครื่องมือ การตั้งค่า และการแก้ไข/ลบ Prompt ของผู้อื่น พร้อมเวลาและ IP |

**ระบบลืมรหัสผ่าน** ต้องตั้งค่า SMTP ใน `config/config.php` ก่อน (ดู README หัวข้อ 5.6) ผู้ดูแลมองไม่เห็นลิงก์หรือรหัสผ่านของสมาชิก

ข้อจำกัดเพื่อความปลอดภัย: ผู้ดูแลระงับ ลบ หรือลดสิทธิ์บัญชีที่ตนเองใช้อยู่ไม่ได้ และระบบไม่ยอมให้เหลือผู้ดูแลที่ใช้งานได้น้อยกว่า 1 บัญชี
